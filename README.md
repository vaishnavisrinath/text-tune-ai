# text-tune-ai
Text to Music generator application using GPT-3 and MusicGen LLM's

For Demo :

Create a folder 'text-tune-ai'
Follow commands in textTuneAI.ipynb - High Compute / Collab Pro is recommended.
Genrate an openai api_key and replace in the file(Follow OpenAI instructions to generate the key).
Create a folder for output music.
Execute the file textTuneAI.ipynb, one cell at a time tweaking theme and output music duration.
